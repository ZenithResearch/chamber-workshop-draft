| Page | Content to fill |

Plain HTML and CSS; no browser JavaScript, framework, dependencies or build step. Run `python3 -B -u server.py` and visit http://127.0.0.1:8767.

The previous repository remains at `../workshop-agenda`. Reference notes are kept outside this repository at `../Workshop_Reference_Notes_2026-11-04.md`. Neither those notes nor previous workshop content is included in this website. The preview server exposes only the two HTML pages and stylesheet.
